# EDCC - Elite Dangerous Command Center

This repository distributes **Windows release binaries only**. It does not contain the application source code.

## Downloads

Download the latest release from [Releases](https://github.com/Mubloxi/EDCC/releases/latest). Each release provides the standalone `edcc.exe` and the Windows NSIS setup installer (`.exe`). Check the release notes for the exact version and verification details.

The published installer for `0.2.0-beta.1` has SHA-256 `24c440a4e779837b42041f7bffdd475b56a71fc42e72199eb1edfef119c999d8`, matching the linked [VirusTotal report](https://www.virustotal.com/gui/file/24c440a4e779837b42041f7bffdd475b56a71fc42e72199eb1edfef119c999d8).
