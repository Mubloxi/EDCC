# Introducing EDCC - Elite Dangerous Command Center

o7 Commanders!

I've been working on **EDCC (Elite Dangerous Command Center)**, an all-in-one Windows companion application for Elite Dangerous.

The idea behind EDCC is simple: **bring the tools and information you normally need across several websites and applications into one place.**

Instead of constantly switching between browser tabs, community tools and the game, EDCC makes useful information and workflows easier to access from one desktop application.

## What does EDCC bring together?

EDCC brings together features and access to established Elite Dangerous community resources, including:

- **INARA** - Commander information, engineering, materials and other community resources.
- **EDDiscovery** - Exploration information, journal history and native cartography panels.
- **Spansh** - Galaxy routing and journey planning tools.
- **EDSY** - Ship builds, outfitting and loadout planning.
- **EDSM** - Star-system information, exploration data and travel history.
- **Elite Observatory** - Exploration and exobiology-related community resources.


The goal isn't to replace these incredible community projects, but to make their tools and information more convenient to access.

Integration capabilities vary by service; some features use local journal data, while others link to or query community services.

EDCC is an independent community project and is not officially affiliated with Frontier Developments or the developers of the services listed above.

## Main Features

### Galactic Data

Search and access useful information across the Elite Dangerous galaxy from one place.

Galactic Data brings together tools for finding nearby stations, trade routes, commodities, engineering components, ship outfitting, and more.

It also provides access to GalNet news and several community data resources.

![EDCC - Galactic Data](https://edcc.lol/app-shots/gallery-161744.png)

### Commander Dashboard

Get an overview of your Commander and recent activity directly from your game journals.

The dashboard displays credits, ships owned, tracked materials, distance travelled, discovered systems, combat kills, current system information, and activity statistics.

![EDCC - Commander Dashboard](https://edcc.lol/app-shots/gallery-161757.png)

### Commander Profile

View detailed information about your Commander, including:

- Credits and current location
- Current ship and squadron
- Combat, trade, exploration and exobiology ranks
- Superpower reputation
- Unlocked engineers
- Commander milestones and achievements
- Credit history

Information is synchronized from your Elite Dangerous journal data.

![EDCC - Commander Profile](https://edcc.lol/app-shots/gallery-161808.png)

### Journal Log

Browse the events recorded by Elite Dangerous in a searchable journal viewer.

Review events such as travel, ship changes, missions, discoveries, engineering and other Commander activity.

The journal viewer provides filtering, event categories and detailed information about recorded events.

![EDCC - Journal Log](https://edcc.lol/app-shots/gallery-161822.png)

## Fleet Operations

### My Ships - Fleet Management

View your ships in one place, with a visual overview of your fleet.

EDCC reconstructs your hangar using game journal information, including stored ships, shipyard changes and loadout snapshots.

Review ship details, fleet value, engineering information and individual ship statistics.

![EDCC - My Ships and Fleet Management](https://edcc.lol/app-shots/gallery-161832.png)

### Ship Catalogue

Browse the available ships in Elite Dangerous and compare their specifications.

Filter ships by manufacturer, size, name and price range, and explore information such as speed, jump range, shields, armour and other ship characteristics.

![EDCC - Ship Catalogue](https://edcc.lol/app-shots/gallery-161843.png)

### Shipyard and Builds

Create, save and manage ship builds using EDCC's integrated shipyard interface.

Review builds, engineered modules and individual loadouts without constantly switching between external applications.

![EDCC - Shipyard and Saved Builds](https://edcc.lol/app-shots/gallery-161902.png)

#### Ship Build Editor

Inspect and modify ship loadouts with the outfitting interface.

Review core and optional internal modules, engineering modifications, experimental effects, module statistics and outfitting costs.

The interface also includes options for finding ships and modules.

![EDCC - Ship Build Editor](https://edcc.lol/app-shots/gallery-161913.png)

### Community Ship Builds

Browse community ship builds organized by their intended purpose.

Categories include hauling, combat, exploration, mining, anti-Xeno activities and specialist builds.

![EDCC - Community Ship Builds](https://edcc.lol/app-shots/gallery-161932.png)

## In-Game Overlays

EDCC includes an overlay system designed to display useful information while playing Elite Dangerous.

This includes travel and docking panels and other journal-based views, allowing Commanders to access relevant information without constantly switching away from the game.

---

## Additional Features

- **Community resources:** Access a range of Elite Dangerous community tools from one application.
- **Customizable interface:** Personalize EDCC's appearance.
- **Local-first design:** Use local game data where possible, with optional online integrations.
- **Journal integration:** Automatically obtain useful Commander information from Elite Dangerous game journals.
- **Exploration tools:** Access galaxy, system, travel and scanning information.
- **Engineering tools:** Track materials, inspect modifications and manage ship builds.
- **Active development:** Features, fixes and improvements are ongoing.
