# Introducing EDCC - Elite Dangerous Command Center

o7 Commanders!

![EDCC](https://forums.frontier.co.uk/attachments/edcc-png.472378/)

I've been working on **EDCC (Elite Dangerous Command Center)**, an all-in-one Windows companion application for Elite Dangerous.

The idea behind EDCC is simple: **bring the tools and information you normally need across several websites and applications into one place.** Instead of constantly switching between browser tabs, community tools and the game, EDCC makes useful information and workflows easier to access from one desktop application.

## What does EDCC bring together?

EDCC brings together features and access to established Elite Dangerous community resources, including:

- **INARA** - commander information, engineering, materials and other community resources.
- **EDDiscovery** - exploration information, journal history and native cartography panels.
- **Spansh** - galaxy routing and journey planning tools.
- **EDSY** - ship builds, outfitting and loadout planning.
- **EDSM** - star-system information, exploration data and travel history.
- **Elite Observatory** - exploration and exobiology-related community resources.

The goal isn't to replace these incredible community projects, but to make their tools and information more convenient to access. Integration capabilities vary by service; some features use local journal data, while others link to or query community services.

EDCC is an independent community project and is not officially affiliated with Frontier Developments or the developers of the services listed above.

## Main features

### Commander and Galactic Data

View commander information such as your current ship, credits, location, ranks, reputation, engineers, milestones and journal activity, using data recorded by the game.

Explore **Galactic Data** tools for star systems, nearby stations and services, commodity searches, trade planning, outfitting, engineering materials and community goals. Search results come from bounded community sources; availability and coverage depend on those sources.

![Galactic Data screenshot](https://forums.frontier.co.uk/attachments/screenshot-2026-11-17-161757-png.472377/)
![Galactic Data screenshot](https://forums.frontier.co.uk/attachments/screenshot-2026-11-17-161744-png.472376/)

### Ship management and builds

Explore ship information, review journal-recorded loadouts, and use the shared outfitting and build interface to plan and manage ship builds.

![Ship build screenshots](https://forums.frontier.co.uk/attachments/photo-collage-png-png.472374/)

### Galaxy exploration and travel

Access galaxy information, exploration tools and route-planning resources for journeys across the galaxy.

![Exploration screenshot](https://forums.frontier.co.uk/attachments/photo-collage-png-1-png.472375/)

### In-game overlays

EDCC includes an overlay system designed to display useful information while playing Elite Dangerous, including travel and docking panels and other journal-based views.

![In-game overlay screenshot](https://forums.frontier.co.uk/attachments/screenshot-2026-11-17-161924-png.472379/)

### Additional features

- **Community resources:** Open and use a range of Elite Dangerous tools from one app.
- **Customizable interface:** Personalize EDCC's appearance.
- **Local-first design:** Use local game data where possible, with optional online integrations.
- **Active development:** Features, fixes and improvements are ongoing.
